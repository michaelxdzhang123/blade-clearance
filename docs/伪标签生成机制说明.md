# 伪标签生成机制说明

日期: 2026-09-17
项目: blade-clearance (YOLO26n-seg 叶片实例分割)

---

## 一、定义: 伪标签(pseudo-label)是什么

伪标签是半监督学习(semi-supervised learning)的核心机制:

> 用已经训练好的模型(teacher)对"没有人工标注"的数据(unlabeled)做推理,
> 把模型给出的高置信度预测当作"标签"使用 —— 这就是"伪标签"。

核心假设(why 有效):
- teacher 在 labeled 数据上已经学会了目标的基本特征;
- 它对 unlabeled 数据的高置信度预测大概率是对的;
- 把这些"伪标签"和真实标签混在一起继续训练, 相当于给模型喂了更多(带噪声的)
  监督信号, 让它见到 labeled 集之外的数据分布, 从而提升泛化。

关键权衡:
- 伪标签是"模型自己考自己", 必然有噪声;
- 所以必须用高置信度阈值保守过滤 —— 只采信"teacher 很有把握"的预测, 宁缺毋滥。

## 二、生成程序定位

```
文件:  yolo26n-seg/train_blade_yolo26_semisupervised.py
函数:  generate_pseudo_labels()        (line 250–375)
调用:  main() 里, Stage1 之后、Stage2 之前 (line 523–535)
```

流程在 main() 中的位置:

```
1. Stage1    : 在 auto-labeled(284 张)上从零训出 teacher (best.pt)
2. 【伪标签】  generate_pseudo_labels(teacher, unlabeled 970 张)
3. 合并       : auto-labeled + 伪标签 → combined_dataset
4. Stage2    : student 从 teacher 权重 warm-start, 在 combined_dataset 上继续训
```

## 三、具体机制(代码逻辑)

### 第一步: teacher 推理

```python
teacher.predict(source=unlabeled 图, imgsz=640, conf=0.75, iou=0.60, stream=True)
```

注意: conf=0.75 是在 predict 阶段就过滤的 —— 置信度 <0.75 的框根本不会出现在
结果里, 所以 result.boxes 里只剩 conf≥0.75 的候选。

### 第二步: 每张图每个预测的三重保守过滤(缺一不可)

| 过滤 | 条件 | 目的 |
|------|------|------|
| ① 置信度 | score < conf_threshold(0.75) → 拒绝 | predict 已按 0.75 过滤, 二次保险 |
| ② 退化 mask | polygon 顶点数 < min_polygon_points(6) → 拒绝 | 顶点太少 = 退化成点/线, 非真实叶片轮廓 |
| ③ 碎 mask | 归一化面积 < min_area_ratio(1e-4) → 拒绝 | 面积太小 = 碎片噪声, 非叶片 |

### 第三步: 写伪标签

通过三重过滤的 mask, 保留完整 polygon(不做 approxPolyDP 简化, 保真度优先),
写成 YOLO-seg 格式一行(归一化坐标):

```
<class_id> <x1 y1> <x2 y2> ... <xn yn>
```

### 第四步: 落盘两个产物

1. `combined_dataset/images/train` + `labels/train`
   = 284 张 auto-labeled(真实标签) + accepted 伪标签
2. `pseudo_label_audit.csv` —— 审计文件, 逐图记录:
   `source_image / accepted_instances / mean_confidence / status`
   (status ∈ {accepted, empty_included, rejected_no_confident_mask})

## 四、关键设计意图(代码注释写明的 why)

代码注释原话: "错误伪标注会污染 Stage-2 训练, 故阈值故意保守"

伪标签是弱监督信号, 一旦 teacher 判错(把背景当成叶片), 这个错误会直接进入
训练集, 伤害 student。所以 conf=0.75 + 三重过滤是"宁缺毋滥"的保守策略。

## 五、相关参数默认值

| 参数 | 默认值 | 含义 |
|------|--------|------|
| --pseudo-conf | 0.75 | 伪标签置信度阈值 |
| --pseudo-iou | 0.60 | NMS IoU 阈值 |
| --min-polygon-points | 6 | 最小 polygon 顶点数 |
| --min-area-ratio | 1e-4 | 最小归一化面积(整图面积=1.0) |
| --include-empty-pseudo | OFF | 是否把"无检出"的 unlabeled 图当作空背景图纳入(默认关) |

## 六、2026-09-17 本次为何 0 采用

本次 970 张 unlabeled 全部 rejected_no_confident_mask, 原因:

新 teacher(640×640 letterbox 训练)对 unlabeled 的置信度系统性偏低:

```
conf≥0.25 → 46%
conf≥0.50 → 2.5%
conf≥0.75 → 0%
```

峰值够不到 0.75, 所以在第一步 predict(conf=0.75)就被全部滤掉,
根本进不到后面两重过滤。

对照: 旧 teacher(640×360 训练)时 conf≥0.75 有 36%, 伪标签本该能采到。

根因: 640×640 letterbox 把 16:9 的叶片缩进中间 640×360 区域(上下各 140px 灰边),
叶片在整图占比变小 → 模型对叶片的置信度整体下移, 够不到 0.75。

## 七、一句话总结

- 伪标签 = teacher 的"高置信度预测"转成的训练标签;
- 生成程序 = generate_pseudo_labels();
- 门槛 = conf 0.75 + 顶点数 6 + 面积 1e-4;
- 本次失效 = letterbox 让叶片变小、teacher 置信度整体下移, 够不到 0.75。
